## Driver Approval Steps

1. Create the driver Auth account.
2. Confirm driver can log in.
3. Confirm `drivers` profile exists for the user.
4. Verify full name, phone, vehicle make/model, plate number, and Gwanda operating area.
5. Review submitted documents.
6. Approve only the 5 named pilot drivers.
7. Ask the driver to open the app and grant location permission.
8. Ask the driver to go online.
9. Confirm the driver appears in admin or live location views.
10. Run one offer test before the first live rider.

## Phone And WhatsApp Confirmation

- Confirm each driver has the pilot support WhatsApp number saved.
- Confirm each driver can receive a WhatsApp message from the operator.
- Confirm each rider has the pilot support phone number.
- Do not put riders in the driver operations group.
- Keep one operator responsible for logging every support interaction.

## Location Permission Checklist

Drivers:

- [ ] Browser or mobile app location permission set to allow.
- [ ] Device location services enabled.
- [ ] Driver can go online.
- [ ] Driver position updates while app is open.
- [ ] Driver knows not to close the app during an active pilot shift.

Riders:

- [ ] Browser or mobile app location permission set to allow.
- [ ] Rider can set pickup manually if GPS fails.
- [ ] Rider can confirm pickup text before requesting.

## Notification Permission Checklist

Drivers:

- [ ] Browser/mobile notification permission allowed.
- [ ] Sound volume high enough.
- [ ] Vibration enabled if device supports it.
- [ ] WhatsApp fallback available.

Riders:

- [ ] Browser/mobile notification permission allowed.
- [ ] Rider understands to stay in the app while waiting for offers.
- [ ] WhatsApp/support fallback available.

## Payment Safety Setup

- Keep app payment providers disabled.
- Tell all pilot users this is a cash-first pilot.
- Manual wallet deposits and withdrawals require operator approval.
- Do not manually edit wallet balances without finance approval.
